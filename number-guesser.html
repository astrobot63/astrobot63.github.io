Project 01

Number Guesser

Number Guesser is a browser-based guessing game where you try to find a randomly generated number.

Play Number Guesser →

What is it?

Number Guesser is a game I built for the web. The player has to guess a randomly generated number, with different difficulty levels providing different number ranges.

Difficulty

The game includes Beginner, Normal, Hard, and Nightmare difficulties. The possible number ranges become larger as the difficulty increases.

Features

Multiple difficulty levels · Random number generation · Simple gameplay · Browser-based experience

HTML · CSS · JavaScript
