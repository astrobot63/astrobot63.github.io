Slide It

Slide It is a sliding puzzle game where players arrange numbered tiles into the correct order.

Play Slide It →

What is it?

Slide It is an interactive sliding puzzle game. Players move tiles around the board and try to solve the puzzle in as few moves and as little time as possible.

Features

Multiple board sizes · Move tracking · Time tracking · Score system

Built with

HTML · CSS · JavaScript · Supabase
